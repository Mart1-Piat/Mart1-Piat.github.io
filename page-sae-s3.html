Projet Transversal - DOO - SQL - API REST - PHP

Dans le cadre du semestre 3 du BUT Informatique, ce projet consistait à concevoir une plateforme de création et de gestion de groupes d’étudiants pour les services d’enseignement. L’objectif était de permettre l’organisation automatique de groupes à partir des informations des promotions et des étudiants.

Le système repose sur une base de données et une API REST permettant de gérer les données (étudiants, promotions, groupes) et de générer des groupes équilibrés selon différents critères. Une interface cliente interroge cette API pour accéder et modifier les données et visualiser les groupes générés.

Ce projet a permis de travailler la modélisation de données, l’utilisation de SQL dans une application, la conception orientée objet, ainsi que la mise en œuvre d’algorithmes de génération de groupes, et la création et l'interrogation d'une API REST. Il a également été réalisé en travail d’équipe, avec utilisation de Git et des livrables techniques réguliers.
